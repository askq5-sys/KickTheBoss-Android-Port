# Kick the Boss 3.0.0 — исходники и как всё устроено

Здесь всё, что мы написали для KTB: русская локализация, отдельное приложение на шелле ZettaBridge
и правки ядра шелла. Оригинальных файлов игры (APK, Assembly-CSharp.dll, sharedassets) здесь нет —
они у тебя в `Desktop\ktb\архив_KTB` и в WSL в `~/ktb_archive`.

Готовая игра: `Desktop\Kick the Boss 3.0.0.apk` (48,9 МБ).

## Что в папках

### 1_перевод
`KTB_перевод_RU_актуальный.xlsx` — финальная таблица перевода (твоя правка + 3 укороченные реплики
босса). Главный файл, если захочется что-то поменять в текстах.

### 2_локализация — как собирался патч
Скрипты, которыми из оригинальной игры делались изменённые файлы. Писались на ходу, пути внутри
жёстко прописаны под мою рабочую папку (`/tmp/claude-0/...`), так что «запустить как есть» не выйдет —
это скорее документация того, что и как менялось.

| скрипт | что делает |
|---|---|
| `patch_il.py` | Патч кода игры (`Assembly-CSharp.dll`, Mono IL), 10 шагов: 10 языков вместо 9, чтение 10-й колонки текстов, панель языков с русским флагом, «ОЦЕНИ!»/«Разработано» только для RU и т.п. |
| `patch_csv.py` | Вписывает русский столбец в текстовые таблицы игры (подсказки, оружие, магазин, сообщения, реплики) |
| `glyph.py`, `buildfonts.py` | Рисуют кириллические глифы и пересобирают атласы 5 шрифтов игры |
| `sa0.py` | Собирает `sharedassets0.assets`: шрифты, флаг RU (текстура 436/материал 437), «Оценить» (438/439), вкладки |
| `tabdefs.py`, `tabs.py` | Переведённые вкладки меню (Оружие / Магазин / Опции) |
| `maindata.py`, `prefab.py` | Правки `mainData` и префабов (копии персонажей Bald/Dork/Lady/Ugly, кнопки) |
| `rate.py` | Надпись «Оценить» |
| `zoppatch.py` | Пережатие APK zopfli (уменьшение размера) |
| остальные (`cmp*.py`, `check.py`, `uvscan*.py`, `md.py`, `ta.py`, `tk2d.py`) | Вспомогательные: сравнение шрифтов, проверки, поиск UV-координат |

- `графика/` — готовые новые текстуры (флаг, «Оценить», атласы шрифтов, HUD, интро, вкладки).
- `данные/` — промежуточные данные (`fonts.pkl` — готовые глифы, `rects*.pkl`, `tabs.pkl`).
- `библиотеки/` — мои мини-библиотеки, которые импортируют скрипты: `sf.py` (чтение Unity-ассетов),
  `cli.py` (разбор .NET-сборок), `axml.py`, `dex*.py` и др.
- `шрифты_OFL/` — свободные шрифты (лицензия OFL), из которых рисовалась кириллица.

### 3_патч_для_установки — главное для пересборки
- `ktb_ru_patch12z.zip` — финальный патч (md5 `0080ca45…`): уже готовые изменённые файлы игры.
- `ktb_ru_apply4.py` (md5 `ae6a36a0…`) — вшивает патч в игру внутри шелла и обновляет `game.version`.
  Оригинальный `game.apk` он сохраняет в `~/ZettaBridge/.ktb_backup/`.

### 4_шелл
- `сборка_приложения/` — отдельное приложение «Kick the Boss»:
  - `zb_make_ktb_app.py` — вариант сборки `kicktheboss` (`com.zettabridge.kicktheboss`), игра внутри APK,
    импорт при первом запуске, сохранения не теряются;
  - `zb_ktb_bundled_ui.py` — одна запись в недавних, «Обновление игры…» на 10 языках;
  - `ktb_final.py` — финальная чистка и версия 3.0.0.
- `правки_ядра/` — исправления и ускорения ядра, сделанные во время работы над KTB (атомарный STREX,
  сигналы, пути libEGL, кэш eglGetProcAddress, быстрее mmap) и `zb_cleanup.py`, который убрал отладку.
- `правки_ядра_старые_игры/` — общие исправления для старых игр, сделанные позже (пробел в GL_EXTENSIONS,
  старый `fseek`, IMEI на Android 10+, распаковка PVRTC). Для KTB не нужны, но лежат в шелле.

Все скрипты шелла уже применены к твоему `~/ZettaBridge` — повторно запускать их не надо
(они это проверяют и пишут «already patched»).

## Как пересобрать KTB, если понадобится

**Вкладка WSL** (из оригинального шелла с уже сделанным вариантом `kicktheboss`):
```
cd ~/ZettaBridge && python3 ktb_ru_apply4.py ~/ZettaBridge ktb_ru_patch12z.zip && cd android/launcher && ./gradlew assembleKickthebossRelease
```
Если менялось ядро шелла (C++), перед gradle нужно ещё:
```
cd ~/ZettaBridge && ninja -C build/android-arm64 zbridge zbproxy && sh tools/make_launcher_bundle.sh
```
а если гостевые библиотеки — `NDK=~/Android/Sdk/ndk/29.0.14206865 NDK_HOST=linux-x86_64 sh tools/build_guest.sh`.

Готовый APK: `android/launcher/app/build/outputs/apk/kicktheboss/release/`.

Если поменять тексты в таблице — нужно заново собрать `ktb_ru_patch*.zip` (скрипты из
`2_локализация`), напиши мне, и я соберу.
