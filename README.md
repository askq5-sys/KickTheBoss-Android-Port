# Kick the Boss 3.0.0 — Android Port

An unofficial compatibility port of the classic **Kick the Boss** game for modern Android devices.

## Features

- ARMv7 (32-bit) compatibility on ARM64 Android devices
- Modified ZettaBridge runtime
- Unity 4 and Mono compatibility improvements
- Legacy Android API fixes
- Performance and stability improvements
- Russian localization
- Standalone Android application

## Tested Device

Samsung Galaxy Z Flip6 — Android 17.

## Building

The project was developed using WSL, Android NDK r29, Java 17, CMake, Ninja, Python and Gradle.

The repository contains compatibility patches and development tools. Building requires the original ZettaBridge source revision, the original game files and other required dependencies.
